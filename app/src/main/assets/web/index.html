My Photos

An image URL, a random-image API that returns a new image each time, or a page / JSON listing image URLs. The TV fetches them daily and keeps a few images per link.

Settings Icon

Profiles

Each profile photo appears at the top right of Home. Without a photo, an initial appears on the profile color. Photos are cropped to a centered square. Change names and colors on the TV (Home Settings → Profiles).

Weather

Temperature appears beside the Home clock, with a five-day forecast in Control Center (Weather). Forecasts come from Open-Meteo; until a city is chosen, the TV estimates its location once from its public IP address (ip-api.com).

Lyrics

When an app plays music, a capsule at the top left of Home shows artwork, title and artist. For each new track, the TV asks LRCLIB, a free open database (no key or account), for lyrics: it sends title, artist, album and duration, nothing else, and records nothing. When synced lyrics are available, select the capsule with the remote: a Lyrics button appears to its right. OK shows synced lyrics over the darkened wallpaper; OK again hides them. Without synced lyrics, the button stays hidden. When off, nothing is sent to LRCLIB.

Top Shelf (TMDB)

With a key, Top Shelf for Netflix, Prime Video, Disney+, Apple TV, Max, Paramount+, Canal+ and Crunchyroll shows popular weekly titles on that service in France (when the app does not publish Continue Watching, or that row is off). Free key: themoviedb.org/settings/api (API key or read access token). The key is stored only on the TV.

Unsplash Wallpaper

The Unsplash wallpaper source uses editorial Wallpapers and Nature collections, in 4K on a 4K TV. Free key: unsplash.com/developers (create an app and copy its Access Key; 50 requests per hour are enough). The key stays on the TV.

Add to Phone Home Screen

iPhone: Share → Add to Home Screen. Android: menu ⋮ → Add to Home Screen. The icon keeps the current page code: regenerate the code on the TV and the old icon stops working.

Rename and arrange folders and inputs on the TV. Landscape 16:9 images work best: the TV crops them to the center (20 MB maximum). Holding an app on the TV also offers Rename and Original Image. With multiple profiles, names and hidden apps belong to the current profile; images apply to all profiles.

Install an App (APK)

To install apps, allow local debugging once on the TV: Home Settings → System → Local Debugging, then Always allow.

The file is sent to the TV and installed as-is (200 MB maximum); only .apk files are accepted, not .xapk or .apks bundles. The app then appears on Home. Install apps only from trusted sources; you are responsible for apps installed this way.

The code in this page address is its only protection: anyone who knows it on the same network can control the TV. Do not share it. If a phone that opened the page is lost, regenerate the code on the TV (Home Settings → Phone Page → Regenerate Code).
